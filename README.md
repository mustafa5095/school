## Private tool

Quiz maker (not listed on the dashboard): [quiz-maker.html](quiz-maker.html) — paste a quiz JSON to build a playable quiz, then download the result as a standalone HTML file with **Download Quiz**. The JSON format is in [quiz-template.json](quiz-template.json).

The builder interface is English only. The quiz it produces is bilingual: fill the base keys for Kurdish and the `_en` keys for English and the quiz gets a Kurdish/English switch, otherwise it stays in the single language provided. Before downloading you can choose whether the standalone quiz includes a Home button.
